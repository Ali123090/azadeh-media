- سه‌شنبه: مادر و کودک

- پنجشنبه: چک‌لیست ذخیره‌کردنی
- جمعه: پیش‌نمایش محتوای اینستاگرام هفته

## اصول محتوا
- ۸۰٪ آموزشی، ۲۰٪ فروش.
- سری‌سازی و «قلاب فردا» برای برگشت مخاطب.
- موضوعات فصلی و مناسبتی (پاییز: سرماخوردگی، ویتامین D؛ مهر: پویش صورتی).
- لحن: صمیمی، علمی، محاوره‌ی فارسی؛ امضای کپشن: «👩‍⚕️ دکتر آزاده | داروساز».
- موضوع‌هایی که قبلاً منتشر شده (پوشه‌ی queue/bale و stories/) تکرار نشوند.

## خطوط قرمز (اجباری)
- معرفی یا تبلیغ داروی نسخه‌ای ممنوع. داروهای نسخه‌ای فقط آموزشی و بدون تبلیغ.
- هر توصیه‌ی دوز، تداخل یا شروع مکمل: «با نظر پزشک یا داروساز».
- هیچ ادعای درمانی قطعی یا غیرمستند. اطلاعات پزشکی باید دقیق و رایج‌ترین توصیه‌ی معتبر باشد؛ در صورت تردید، موضوع دیگری انتخاب شود.
- علائم بیماری همیشه با جمله‌ی «علائم اختصاصی نیستن؛ فقط آزمایش/پزشک مشخص می‌کنه».

## سیستم طراحی (طراحی توسط Claude، نه Canva)
- رنگ‌ها: زرشکی تیره #3B0D11، قرمز #A4161A، کهربایی #E9A23B، آفتابی #F4B740، کرم #FFF6EC، صورتی #F7DCD6، سبز بله #00A884
- فونت‌ها: Lalezar برای تیتر، Vazirmatn برای متن (فایل‌ها در ریشه‌ی مخزن)
- ساختار: هدر تیره با تصویرسازی برداری مرتبط با موضوع + بدنه‌ی کرم با کارت‌های سفید + نوار CTA قرمز + @dr.azadehpharma
- رندر: HTML → WeasyPrint → PDF → pdftoppm -r 96 → PNG. در WeasyPrint از flex برای چیدمان RTL استفاده نشود؛ position:absolute. متن فارسی داخل SVG <text> برعکس رندر می‌شود؛ برچسب‌ها با div.
- استوری: فاصله‌ی امن بالا ۲۵۰px و پایین ۲۵۰px.
- قبل از تحویل، پیش‌نمایش هر تصویر دیده و هم‌پوشانی/بریدگی متن اصلاح شود.
- نمونه‌کدها در templates/.

## روند انتشار
1. تصاویر → GitHub با templates/ghup.py (توکن از متغیر GH_TOKEN، مخزن Ali123090/azadeh-media):
   - بله: bale/YYYY-MM-DD/<n>-<slug>.png
   - استوری: stories/YYYY-MM-DD/ig-<n>-<slug>.png
2. صف بله: queue/bale/YYYY-MM-DD-00n-<slug>.json
   {"publish_at":"YYYY-MM-DDTHH:MM:00+03:30","type":"photo","media":"bale/...png","caption":"...","enabled":false}
   تا تأیید علی، enabled باید false باشد. بعد از تأیید → true.
3. استوری اینستاگرام: Metricool createScheduledPost با media = لینک raw.githubusercontent.com، instagramData.type = STORY، و draft = true تا تأیید. بعد از تأیید → updateScheduledPost با draft = false.
4. پل بله روی کامپیوتر داروخانه هر ۱۵ دقیقه صف را می‌خواند (پست‌های بیش از ۶ ساعت دیرتر منتشر نمی‌شوند).
